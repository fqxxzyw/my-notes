纸间 Windows 便携版

1. 请先将 ZIP 中的全部文件解压到有写入权限的文件夹，再双击“纸间.exe”。
2. 请保留与 EXE 同目录的 portable.mode 文件。程序会在同目录创建“纸间数据”文件夹，并将本机草稿、离线副本和设置保存其中。
3. 普通单文件版的数据仍保存在 %LOCALAPPDATA%\PaperNotes，与便携版互不覆盖。
4. 若要从普通版迁移本机数据，请先关闭两个版本，将 %LOCALAPPDATA%\PaperNotes 文件夹内的内容复制到解压目录的“纸间数据”文件夹，再打开便携版。建议先备份原文件。
5. GitHub 令牌使用当前 Windows 账户加密。将便携目录换到其他 Windows 账户或电脑后，可能需要重新连接令牌；笔记数据仍在“纸间数据”中。
6. 不要将包含个人笔记、离线副本或令牌的“纸间数据”文件夹分享给他人。

程序需要 Windows x64、Microsoft Edge WebView2 Runtime 和 .NET Framework 4.6.2 或更高版本。
