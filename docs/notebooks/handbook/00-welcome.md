# 欢迎使用纸间

欢迎来到你的笔记书柜。书柜用来整理笔记本，一本笔记本可以包含多个章节；所有章节都使用 Markdown 保存。

## 新建第一本笔记

点击顶部的「新建笔记」，输入名称，再选择要放入的书柜。你也可以在创建时新建书柜；如果不选择，就会放进「默认书柜」。打开笔记本后，可以继续创建章节并开始写作。

## 整理你的书柜

进入书柜后，打开「管理笔记本」，可勾选多本笔记，选择目标书柜并点击「移动所选」。在全部书柜页面打开「管理书柜」可以删除其他书柜：其中的笔记本会移入默认书柜，内容不会随书柜一起删除。默认书柜始终保留。

## 同步与恢复

你可以先写本机草稿，再准备自己的 GitHub 仓库：创建仓库时添加 README 并确保有 `main` 分支。私密笔记可选择私有仓库；公开仓库的笔记任何人都可以查看。

在「GitHub 同步设置」中填写自己的仓库地址或 `用户名/仓库名`。创建只允许访问该仓库、Contents 为 Read and write 的精细访问令牌，连接后就能勾选本机改动并点击「同步」，将笔记发送到 GitHub。点击「恢复」可以读取 GitHub 的最新内容并保存到本机，尚未同步的草稿会保留。

桌面版整理或删除书柜后，点击「同步书柜整理」将变动提交到 GitHub。网页版连接后，如果启用了自动保存，会自动同步书柜整理。

在笔记本或章节的管理入口选择删除时，确认提示会说明操作范围。删除已经同步的内容需要连接 GitHub；远端内容发生冲突时，请先恢复并检查，再决定如何处理。

令牌相当于仓库钥匙，请勿分享或写进笔记；网页与桌面版需分别连接。你可以在「GitHub 同步设置」中打开使用指南，查看建仓和创建令牌的详细步骤。

你也可以继续阅读后面的章节，了解笔记结构和同步方式。后续章节如提到「新建笔记本」或「读取最新目录」，对应当前的「新建笔记」和「恢复」。
