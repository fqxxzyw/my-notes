# 01 · 前端、官网与资源代码详解 (`src/`、`website/`、`public/`、`resources/`)

很多新手容易混淆 `src/` 和 `website/`，其实它们是两个完全独立的前端：
- **`src/`** 是 **软件本体** 的界面（打包成桌面客户端或本地 Web 端，跑在 Electron 窗口里）。
- **`website/`** 是 **官方网站**（部署在服务器上给所有人浏览、下载安装包、管理账号的网页）。

---

## 1. 官网代码在哪里？(`website/`)

`website/` 是一个**纯原生静态网站**（没有用 React 或 Vue，直接用原生 HTML + CSS + ES Module JS，加载极快，适合直接托管在 Cloudflare Pages 上）：
- `website/index.html`：官网主页面（展示雪乃介绍、各套服装预览、场景展示、下载按钮、网页版账号中心）。
- `website/assets/config.js`：配置后端 API 地址（默认 `apiBase: ''` 表示同源请求）。
- `website/assets/app.mjs`：官网交互逻辑（登录注册弹窗、拉取最新版本下载链接）。
- `website/assets/release-downloads.mjs`：动态获取软件安装包下载地址。
- `website/assets/*.css`：官网样式表（毛玻璃、苹果风排版、响应式布局）。
- `website/assets/outfits/` & `scenes-hq/`：官网展示用的高清服装抠图与场景图。

---

## 2. 软件前端代码在哪里？(`src/`)

软件前端使用 **React 19.3 + Vite 8.3** 构建，共有 3 个 HTML 入口（在项目根目录）：
1. `index.html` → 对应 `src/main.jsx`（主聊天与陪伴窗口）
2. `model-window.html` → 对应 `src/model-window.jsx`（独立 3D 模型预览/设置窗）
3. `visual-window.html` → 对应 `src/visual-window.jsx`（视觉交互/摄像头窗口）

### `src/` 内部四大模块：
| 子文件夹 | 职责 | 重点文件举例 |
| :--- | :--- | :--- |
| **`src/ui/`** | **所有界面组件与交互** | `AccountCenter.jsx`（账号中心）、`BilingualBubble.jsx`（双语气泡）、`CharacterPanel.jsx`（角色面板）、`PetAvatar.jsx`（3D 形象控制）、`BlackboardOverlay.jsx`（教室黑板互动）、`blink-scheduler.mjs`（自动眨眼）。 |
| **`src/companion/`** | **角色大脑与数值系统** | `relationship.mjs`（好感度系统）、`skin-unlocks.mjs`（皮肤解锁判定）、`automatic-memory.mjs`（从聊天中自动提取记忆）、`touch-interaction.mjs`（摸头/点击反馈）。 |
| **`src/scenes/`** | **Three.js 3D 场景** | 用代码画出来的 3D 场景：`classroom.mjs`（教室）、`sakura-stream.mjs`（樱花溪流）、`kyoto-temple.mjs`（京都寺庙）、`bookshop.mjs`（书店）等。 |
| **`src/speech/`** | **语音前端调度** | `microphone-capture.mjs`（麦克风录音）、`segmenter.mjs`（长句切分，实现边生成边说话）、`scheduler.mjs` & `player.mjs`（语音队列播放与口型同步）。 |

## 3. 重点学习：流式语音切分器 (`src/speech/segmenter.mjs`)

为什么 AI 说话不能等整段字都生成完再合成语音？因为那样用户要等好几秒才听到声音。
`segmenter.mjs` 的作用是：**AI 每吐出几个字，就立刻判断能不能切成一个短句送去语音合成**。

它的设计非常巧妙：
1. **中英文按"朗读时长"加权（`weight()`）**：
   - 中文 1 个字算 `1.0`；英文字母 1 个算 `0.25`；空格算 `0.25`；数字算 `0.5`。
   - 这样设置上限 `maxSegmentChars: 80` 时，无论是中文还是英文，朗读出来的耗时都差不多，不会把英文单词切碎。
2. **标点分级 + 保护机制**：
   - 遇到强句号（`。！？\n`）立刻切分。
   - 遇到逗号（`，、`）时，只有当前长度达到目标长度的 75% 才切，避免切出两三个字的碎片。
   - 通过括号栈和 `urlRanges()` 识别成对引号（`「」`、`""`）以及网址（`https://...`），保证不会在引号没闭合前或网址的 `.` / `:` 处误切。

## 4. 资源文件都在哪里？(`public/` vs `resources/`)

很多新手分不清 `public/` 和 `resources/`：
- **`public/`（打包给前端网页直接加载的静态文件）**：
  - `public/characters/*.glb`：雪乃的 3D 模型文件（和服、夏装、泳装、冬装、旗袍、贝雷帽等）。
  - `public/wallpapers/`：默认天空壁纸。
  - `public/audio/pcm-capture-worklet.js`：浏览器 AudioWorklet 底层录音线程脚本。
  - `public/provider-logos/`：各大 AI 厂商（OpenAI、DeepSeek、阿里云等）的图标。
- **`resources/`（给桌面端主进程 / Python 读取的配置文件与资源包）**：
  - `resources/voice-models.json`、`translation-models.json`、`runtime-catalog.json`：告诉软件去哪里下载模型包、校验文件大小和哈希。
  - `resources/voice-presets/yukino-reference.wav`：雪乃默认的声音克隆参考音频。
  - `resources/live2d/`：Live2D 2D 形象的运行时与参数配置。
