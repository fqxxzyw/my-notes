# 写作与整理

进入书柜，点击书脊打开笔记本，在章节目录中创建章节。书本较多时，可以按住书架横向拖动，触屏设备可以左右滑动。

点击顶部「导入」或直接拖入 Markdown 文件：在笔记本中会新增章节，在书柜中会创建独立书页。导入文件夹会创建一本笔记本，并一起导入文件夹内可匹配的相对路径图片。Windows 桌面版通过「选择文件」或「选择文件夹」选中 Markdown 时，还会尝试读取其中引用的本机绝对路径图片；图片缺失时会提醒检查。

章节编辑器自动保存当前设备上的草稿。桌面版和网页版分别保存草稿；清理浏览器网站数据或桌面应用用户数据前，请先同步或备份需要的内容。

在编辑器中可直接粘贴 PNG、JPEG、GIF、WebP 图片，每张最多 20 MiB。图片会作为独立附件保存，正文使用 `assets/图片文件名.png` 这样的相对路径；同步笔记时图片会一起上传，恢复后可离线查看。网页版导入时请选择包含图片的文件夹；无法读取的图片和其他附件不会自动导入。已导入的笔记可在「导入」中选择「补齐当前笔记图片」并选择原始文件夹；图片位于其他位置时，也可选择「从图片文件夹补齐」并确认匹配结果。桌面版还可选择「选择原笔记自动补齐」，按原 Markdown 中的本机地址读取图片。

编辑时可在侧栏切换「章节」与「目录」；目录会列出当前章节的标题，点击可跳转。也可以收起侧栏扩大写作空间，再点击「显示目录」展开。

Windows 便携版把本机数据放在解压目录下的「纸间数据」文件夹；移动或备份程序时，请一并保留它。

桌面版图片位于数据目录的「附件」文件夹（单文件版为 `%LOCALAPPDATA%\PaperNotes\附件`，便携版为解压目录下的 `纸间数据\附件`），并按仓库隔离。网页版图片存放在当前浏览器的 IndexedDB，清除网站数据前请先同步或备份。

在「管理笔记本」中选择多个笔记本，可一起移动到其他书柜。删除非默认书柜会把其中笔记本移入默认书柜。默认书柜始终保留。
