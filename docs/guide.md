# 使用纸间

[回到我的书柜](/)

## 从书柜开始

首页展示所有书柜。点一个柜子，会看到里面的笔记本立在同一排。鼠标移到书脊上可放大查看书名，点一下打开目录。手机可以左右滑动这排书。用页面顶部的路径返回上一级。

点「新建书柜」为一个大类留位置，例如「工作」。进入书柜，点「新建笔记本」，例如「项目记录」。打开笔记本，点「添加章节」开始写作。想换位置时，在笔记本目录的「所在书柜」中选择目标柜子。

## 写作与保存

章节使用 Markdown。写作时，草稿保存在当前浏览器里。回到同一台设备、同一个浏览器，可以继续上次的内容。清除网站数据会清除本机草稿。

**网页版**：点击「连接并自动保存」。此后新建笔记本、添加章节或修改正文，停笔后网页就会将改动提交到 GitHub。离开页面前查看保存状态；遇到网络中断或版本冲突，先保留本机草稿，按提示处理。

**本地版**：运行 `npm run docs:dev` 并打开本机书架。写完后连接 GitHub，在「批量同步」里勾选章节，点击「同步所选」。选中的章节写入同一次提交，其余草稿继续留在本机。这个按钮直接提交到 GitHub；要在本地 Git 工作目录中取得这些文件，可以运行 `git pull --ff-only`。

两种方式都按原文保存。新建内容立即出现在当前书架上。写入仓库后，其他设备可以点「读取最新目录」查看；自动部署完成后，直接打开网站也能看到。

## 连接 GitHub

1. 用有此仓库写入权限的账号打开 [GitHub 的精细访问令牌设置](https://github.com/settings/personal-access-tokens/new)。
2. 选择有效期，在 Repository access 中选 Only select repositories，只选 `my-notes`。在 Repository permissions 中将 Contents 设为 Read and write。
3. 将生成的令牌填入本站的连接窗口。凭据只用于当前页面会话，刷新后需要重新连接。

## 在仓库里找回一章

每本笔记在 `docs/notebooks/` 下有一个目录。`index.md` 记录笔记本名称，其余 Markdown 文件分别对应各章。打开章节文件的 History 即可查看已提交的历史版本。

提交到 `main` 后，GitHub Actions 会重新发布书架。从其他设备查看刚同步的改动时，可以先检查部署是否完成。[查看部署记录](https://github.com/fqxxzyw/my-notes/actions/workflows/deploy.yml)
