# 第二章 · 把原文存进 GitHub

网页版点击「连接并自动保存」后，停笔片刻就会把改动提交到 GitHub。本地运行时，打开「批量同步」，勾选写好的章节，一次提交。两种方式都保留完整 Markdown 原文。

## 笔记放在哪里

一本笔记对应一个目录，一章对应一个 Markdown 文件。打开仓库里的 docs/notebooks，就能找到这些原文。文件名是稳定的标识，打开文件可以看到中文标题。

## 在另一台设备上阅读

同步成功后，在另一台设备上点「读取最新目录」可查看刚提交的笔记。GitHub Actions 重新发布书架后，打开站点也能直接阅读这些章节。未提交的草稿只保存在写作时使用的浏览器。
