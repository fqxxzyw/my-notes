# 第二章 · 把原文存进 GitHub

先在「GitHub 同步设置」中连接自己的仓库和访问令牌。网页版若启用自动保存，停笔片刻后会提交改动；也可以打开「批量同步」，勾选写好的章节，一次提交。桌面版使用批量同步提交本机改动。两种方式都保留完整 Markdown 原文。

## 笔记放在哪里

一本笔记对应一个目录，一章对应一个 Markdown 文件。打开仓库里的 docs/notebooks，就能找到这些原文。文件名是稳定的标识，打开文件可以看到中文标题。

## 在另一台设备上阅读

同步成功后，在另一台设备连接同一个仓库并点击「恢复」，即可下载刚提交的笔记。未提交的草稿只保存在写作时使用的设备。仓库只用于保存笔记时不需要 GitHub Pages；公开展示网站需要另行部署。
